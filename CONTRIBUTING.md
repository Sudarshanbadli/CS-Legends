# Contributing to CS Legends

Thank you for helping document computing history.

## Biography contributions
- Use the person's full, commonly documented name.
- Cite at least two reliable sources; prefer primary or institutional sources.
- Include birth/death years only when verified.
- Describe contributions precisely and distinguish independent invention from collaboration.
- Treat “Father of …” labels as popular/honorary descriptions, not official facts.
- Avoid unsupported superlatives and national-origin assumptions.

## Portrait contributions
- Only add portraits whose individual file page confirms public-domain status or a compatible reuse licence.
- Add complete attribution to `IMAGE_CREDITS.csv`.
- Do not use Google Images thumbnails or images with unclear rights.

## Data format
Edit `data/people.json`. Keep `slug` unique. Use tags for secondary disciplines rather than duplicating the person.
